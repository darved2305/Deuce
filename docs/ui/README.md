# UI concept (starting point, not final)

Owner: **Person 2 (@darved2305)**, who designs the final UI. Everything here can change; the
product rules in `AGENTS.md` do not (real footage under every overlay, one-tap evidence,
denominators, `MODEL ESTIMATE` verdicts, `SIMULATED` labels, almost no text).

- Eight concept screens in Design-canvas format (`*.dc.html`): Today, Add a match, Timeline +
  streaming analysis, Match overview, Rally replay, Compare (similar moment), Review a moment
  (model estimate), Simulation. View them on the canvas:
  https://claude.ai/artifact/3u3xsVsGDwKu69KhBDpPBC (Hetansh shares access). The files need the
  canvas runtime, so opening them directly in a browser will not render correctly.
- Footage is drawn as illustrations because a mockup cannot embed video. In the app every visual
  sits on real footage. All numbers ("You vs Arjun", counts) are illustrative, not engine output.
- Starting design tokens: Ink `#101519` (background), Surface `#1D272D`, Chalk `#F3F0E8`,
  Ice `#62C7D5` (you), Ember `#F39B68` (opponent), Citron `#DCE76B` (ball / key action);
  IBM Plex Sans + IBM Plex Mono; dark-first; haptics tick / click / heavy only.
- Screen-by-screen behaviour and the visual system: `docs/plan/05-app-experience.md`.
