Every rally, as structured data.

Elevate turns one phone video of a badminton match into a match record: shuttle trail, hits, landings in court metres, players and the score. Read it from a REST API, a typed SDK, or straight from Claude through MCP.

Create a read-only developer key, then fetch a match.

# read a finished match
curl https://zpwxjjsugujmihhkmfjx.supabase.co/functions/v1/api/v1/matches/m_7f8db800… \
  -H "X-API-Key: $ELEVATE_API_KEY"
import { DefaultApi, Configuration } from "@elevate/sdk";

const api = new DefaultApi(new Configuration({ apiKey: process.env.ELEVATE_API_KEY }));
const match = await api.v1MatchesIdGet({ id: "m_7f8db800…" });
console.log(match.events.filter(e => e.type === "landing"));

What's in a match record.

Hits come from the shuttle's turn plus the sound of the racket. Landings are projected to court metres through the four corners you tap. Players keep the same id for the whole match.
